# v3 资料同步补丁

本补丁解决两个问题：教师端之前只列出上传目录、没有显示已有的五个 topic 内置资料；
原 `medical_hybrid` 只检索内置快照，没有接入教师上传目录。

安装后，Content 页显示 Built-in materials 和 Uploaded materials，每个文件都有
Searchable / Not searchable、片段数和必要的失败原因。上传接口会等待入库结果，
成功时显示 Uploaded and searchable。解析失败时文件仍保存，明确显示不可检索原因。

## 文件如何参与检索

- 资料仍保存在 `rag.materials_dir/<topic>/`，默认 `data/topics/<topic>/`。
- 内置资料仍是 `data/medical_rag/raw/` 中的五个文本文件，教师上传不会覆盖内置快照。
- 新上传资料解析、分段后加入该 topic 的 BM25、word/character TF-IDF 索引。
- 上传来源标记为 `course/<topic>/<filename>`，可以传给现有证据验证和回答生成流程。
- 同名替换后先前文本会退出索引，避免重复或继续引用旧内容。
- 启动时自动加载已有上传文件；运行时发现目录变化会更新索引，多进程也能分别刷新。
- 不可读文件被排除，错误不会阻止内置资料检索或服务启动。

可检索表示文件已进入 RAG 索引。学生每次提问仍使用原有语义路由及证据相关性、支持性验证；
文件入库不代表所有问题都会走 local，也不会自动把上传资料标为已审核或最新证据。

## 支持格式和限制

| 格式 | 说明 |
|---|---|
| TXT / MD | UTF-8 或带 BOM 的 UTF-16 |
| HTML / HTM | 提取本地正文，忽略脚本和样式，不访问外部链接 |
| DOCX | 段落和表格文字，不识别图片文字 |
| PDF | 有文字层、未加密的 PDF；不含 OCR |

单文件最多 20 MB、500,000 个提取字符，PDF 最多 250 页；DOCX 解压内容最多 64 MB；
每个 topic 的正文预算为 2,000,000 字符。超过限制会显示原因，可拆分文件后重传。
仅含扫描图片的文件会显示未索引，需先 OCR。

## 安装与数据

此增量补丁针对 `Hybrid-AI-Tutor-integrated-v3`，不适用于旧 semantic-routing 分支。
应用脚本会检查目标文件，备份原文件；发现不兼容修改会停止。
不修改 `.env`、数据库、上传资料、配置、训练权重或模型缓存。
只需在原有虚拟环境中更新后端依赖（新增 `pypdf`、`python-docx`），重启前后端。
不用重建虚拟环境，不用重新训练或下载语义模型。

## 验证范围

`backend/tests/test_material_sync.py` 覆盖内置清单、格式解析、上传后检索、重启、替换、
解析失败、topic 隔离、多实例刷新，以及教师上传到学生问题引用的 API 链路。
该链路使用真实检索器和文件解析器，语义分数与回答模型使用测试替身。
`frontend/src/test/Content.test.tsx` 检查内置清单、上传后刷新和解析错误提示。
